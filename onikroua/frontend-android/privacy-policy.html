Politique de confidentialité - Onykroua

Dernière mise à jour : 12 janvier 2026

1. Introduction

Onykroua est une application d'apprentissage de l'italien utilisant l'intelligence artificielle. Cette politique de confidentialité explique comment nous collectons, utilisons et protégeons vos données personnelles.

2. Données collectées

2.1 Enregistrement audio (RECORD_AUDIO)

L'application utilise la permission RECORD_AUDIO pour :

  • Reconnaissance vocale : Enregistrer votre voix pour la reconnaissance de parole lors des exercices de conversation
  • Interaction avec l'IA : Permettre des conversations vocales avec l'assistant IA Gemini

Important :

  • Les enregistrements audio sont traités en temps réel et ne sont pas stockés sur votre appareil
  • L'audio est envoyé aux services Google (Speech Recognition API et Gemini API) pour le traitement
  • Aucun enregistrement audio n'est sauvegardé ou partagé avec des tiers autres que Google
  • Vous pouvez désactiver cette fonctionnalité à tout moment dans les paramètres de l'application

2.2 Données d'authentification

Si vous vous connectez avec Google :

  • Nom et email (fournis par Google Sign-In)
  • Ces données sont utilisées uniquement pour l'authentification et la personnalisation

2.3 Données d'utilisation

  • Progrès d'apprentissage (vocabulaire, grammaire, conversations)
  • Scénarios d'apprentissage sélectionnés
  • Ces données sont stockées dans Firebase Firestore et associées à votre compte

3. Utilisation des données

Vos données sont utilisées pour :

  • Fournir les fonctionnalités de reconnaissance vocale et de conversation IA
  • Personnaliser votre expérience d'apprentissage
  • Sauvegarder votre progression
  • Améliorer l'application

4. Partage des données

Vos données sont partagées uniquement avec :

  • Google Cloud Services : Pour la reconnaissance vocale (Speech-to-Text API) et l'IA conversationnelle (Gemini API)
  • Firebase (Google) : Pour l'authentification et le stockage des données utilisateur

Nous ne vendons ni ne partageons vos données avec d'autres tiers.

5. Sécurité des données

  • Toutes les communications utilisent HTTPS/TLS
  • Les données sont stockées sur des serveurs sécurisés Firebase
  • L'authentification utilise les protocoles sécurisés de Google

6. Vos droits

Vous avez le droit de :

  • Accéder à vos données personnelles
  • Modifier vos informations
  • Supprimer votre compte et toutes vos données
  • Refuser l'utilisation de la reconnaissance vocale

7. Conservation des données

  • Les données audio sont supprimées immédiatement après traitement
  • Les données de progression sont conservées tant que votre compte est actif
  • Vous pouvez supprimer votre compte à tout moment depuis les paramètres de l'application

8. Services tiers

L'application utilise les services suivants, qui ont leurs propres politiques de confidentialité :

  • Google Cloud Platform (Speech-to-Text, Gemini AI)
  • Firebase (Authentication, Firestore)

9. Modifications de cette politique

Nous pouvons mettre à jour cette politique de confidentialité. Les modifications importantes seront notifiées via l'application.
